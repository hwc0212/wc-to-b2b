## 插件概述

**WooCommerce to B2B** 是一个专为B2B企业设计的WordPress插件，将传统的WooCommerce直接付款模式转换为"询价→沟通→报价→确认→付款"的专业B2B工作流程。

**GitHub仓库**: [https://github.com/hwc0212/wc-to-b2b](https://github.com/hwc0212/wc-to-b2b)

## 2.0 B2B 会员报价与线下履约

2.0 版本在原有询盘流程上增加了可实际运营的 B2B 交易闭环：

- **会员等级价**：在“WooCommerce → B2B Member Levels”添加等级、默认折扣，再到用户资料中分配等级。商品和每个变体均可设置等级固定价；固定价优先，未设置固定价时使用等级折扣。
- **在线生成报价**：传统结账和区块版 Checkout 均只显示“Offline quotation”，不会调用任何在线支付网关。可在“WooCommerce → B2B Quote Settings”选择自动生成报价，或由管理员调整价格、运费后人工发送。
- **线下付款资料**：在报价设置中填写银行账户、收款人、SWIFT、付款附言等资料，系统会显示在报价邮件、订单详情和客户中心。
- **收款登记**：管理员可在订单的“B2B Payments & Shipments”区域逐笔登记日期、金额、方式和银行流水号。累计足额后订单自动进入已收款/处理中状态。
- **发货登记**：支持多次/部分发货，记录承运商、单号、查询链接、发货内容和备注；最后一次发货可直接标记全部发货。
- **客户查询**：客户登录“我的账户 → B2B Quotes & Orders”，可查看并打印报价、付款余额、每笔收款和每次发货记录。访客订单通过邮件中的签名链接安全查看。
- **邮件通知**：报价生成、报价接受、付款登记、发货登记和取消等关键变化都会发送邮件；发货邮件包含物流查询信息。

推荐启用“结账时必须创建账户”，以便客户长期登录查询历史记录。旧订单状态和原有邮箱/WhatsApp 验证流程仍保持兼容。

如果旧版本曾启用“Replace add to cart buttons with WhatsApp buttons”，请在原 B2B 设置中关闭该选项，商品页才会恢复加入购物车并进入在线报价结账流程。

## 解决的核心问题

**这个插件解决的根本问题是：传统WooCommerce让客户直接付款，而B2B业务需要在确定订单前先与客户沟通，确定细节后再发送报价给客户。**

### 🎯 **B2B业务痛点**
- **直接付款模式**: 客户看到价格就直接付款，没有沟通和谈判的机会
- **固定价格体系**: 无法根据客户规模、合作关系、采购量灵活调整价格
- **系统兼容性**: 很多公司使用自己的CRM或ERP系统，不方便在WordPress后台操作
- **销售流程**: 销售人员需要完整的客户信息才能快速响应和报价

### ✅ **B2B解决方案**
- **先沟通后付款**: 建立验证→沟通→报价→确认的专业B2B流程
- **灵活报价系统**: 支持个性化定价和谈判
- **系统兼容**: 销售人员可直接通过邮件回复，无需登录WordPress
- **完整信息**: 管理员邮件包含所有必要信息，支持快速响应

### 为什么B2B企业需要这个插件？

传统WooCommerce设计用于B2C直接销售，但B2B业务有着完全不同的需求：

❌ **传统WooCommerce的B2B痛点**：
- **直接付款模式**：客户看到价格就直接付款，没有沟通和谈判的机会
- **固定价格体系**：无法根据客户规模、合作关系、采购量灵活调整价格
- **单一沟通渠道**：只能通过邮件联系，限制了全球化B2B业务发展
- **缺乏验证机制**：无法确保客户信息真实性，容易产生无效订单
- **简单购买流程**：不适合需要多轮沟通和谈判的B2B采购决策

✅ **WooCommerce to B2B的B2B解决方案**：
- **先沟通后付款**：客户提交询价→验证身份→充分沟通→个性化报价→确认付款
- **灵活报价系统**：根据客户需求、采购量、合作关系等因素实时调整价格和运费
- **多渠道沟通**：支持邮箱和WhatsApp双重验证和通知，适应全球客户偏好
- **完整B2B流程**：验证 → 沟通 → 报价 → 确认 → 付款的专业B2B工作流
- **智能通知路由**：根据客户验证方式自动选择最佳沟通渠道，提升沟通效率

### 典型B2B场景示例

**制造业定制**：客户询价定制产品 → 工程师沟通技术要求 → 根据复杂度报价 → 客户确认后付款

**批发贸易**：客户询价批量采购 → 确认库存和交期 → 根据订量给出阶梯价格 → 客户选择合适方案付款

**跨境电商**：海外客户通过WhatsApp询价 → 确认规格和物流方案 → 根据汇率和运费报价 → 客户确认后付款

## 插件概述

**WooCommerce to B2B** 是一个专为B2B企业设计的WordPress插件，它彻底改变了传统WooCommerce的购买模式：

**从 "看价格→直接付款" 转变为 "询价→沟通→报价→确认→付款"**

这个插件将标准WooCommerce转换为具有验证工作流程和报价审批流程的专业B2B订单管理系统，让B2B企业能够：
- 在客户付款前充分了解需求
- 根据具体情况提供个性化报价
- 通过多种渠道与全球客户高效沟通
- 建立专业的B2B采购和销售流程

## 安装说明

1. 将 `wc-to-b2b` 文件夹上传到您的 `/wp-content/plugins/` 目录
2. 通过WordPress的"插件"菜单激活插件
3. 确保WooCommerce已安装并激活
4. 在 WooCommerce > B2B设置 中配置插件

## 安装和配置

### 系统要求
- WordPress 5.0+
- WooCommerce 5.0+
- PHP 7.4+

### 安装步骤
1. 将 `wc-to-b2b` 文件夹上传到您的 `/wp-content/plugins/` 目录
2. 通过WordPress的"插件"菜单激活插件
3. 确保WooCommerce已安装并激活
4. 在 WooCommerce > B2B设置 中配置插件

### 基本配置
- **管理员邮箱**: 接收订单通知的邮箱地址
- **验证过期时间**: 验证链接有效期（默认48小时）
- **订单过期时间**: 订单自动取消时间（默认21天）
- **WhatsApp集成**: 可选功能，需要配置WhatsApp API

### WhatsApp配置（可选）
WhatsApp功能默认关闭，需要手动配置开启：

1. **获取WhatsApp API**: 需要WhatsApp Business API访问权限
2. **配置API信息**: 在插件设置中填入API URL和密钥
3. **启用功能**: 勾选"启用WhatsApp"选项
4. **测试功能**: 确保API连接正常工作

> **注意**: 大部分WordPress网站都配置了邮件发送服务器，所以邮箱验证是默认启用的。WhatsApp功能需要额外的API服务，因此设为可选配置。

## 使用流程

### 1. 客户下单
- 客户填写增强的结账表单（邮箱、电话、留言）
- 订单创建时状态为"待验证"
- 系统自动发送邮箱验证（默认）
- 如果启用WhatsApp，同时发送WhatsApp验证

### 2. 客户验证
- **邮箱验证**: 客户点击邮件中的验证链接（默认方式）
- **WhatsApp验证**: 如果启用，客户也可通过WhatsApp验证
- 任一方式验证成功，订单状态变更为"已验证"
- 管理员收到通知

### 3. 管理员审核和报价
- 管理员审核订单详情和客户留言
- 可修改价格、运费和订单项目
- 发送个性化报价给客户

### 4. 客户确认
- 客户收到报价（通过验证时使用的渠道）
- 可接受报价进入付款流程或取消订单

## 验证方式说明

### 默认验证方式
- **邮箱验证**: 默认启用，适用于所有WordPress网站
- 大部分WordPress网站都配置了邮件发送服务器
- 客户通过点击邮件中的验证链接完成验证

### WhatsApp验证（可选）
- **需要配置**: WhatsApp功能默认关闭，需要手动配置启用
- **API要求**: 需要WhatsApp Business API访问权限和第三方服务
- **配置复杂**: 相比邮件服务，WhatsApp API配置更复杂
- **全球支持**: 启用后可为全球B2B客户提供即时通信支持

### 智能通知策略
- 如果只启用邮箱：所有通知通过邮件发送
- 如果启用WhatsApp：客户可选择验证方式，后续通知使用相同渠道
- 确保通信渠道一致性，避免客户困惑
